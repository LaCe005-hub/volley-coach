# volley-coach

Persönliche PWA für einen Volleyball-Trainer: Aufstellung eintragen, Rotation nach offiziellen Volleyball-Regeln automatisch nachführen (Libero getrennt behandelt), Punktverluste mit Fehlergrund (Aufschlag/Netz/Annahme/Angriff/Block/Sonstige) protokollieren, jederzeit freier Spielerwechsel.

Single-User-Tool, kein Login, offline-first (Halle hat oft kein Internet). Kein Backend nötig.

Details und aktueller Stand: `../10_Weitermachen/weitermachen.md`
